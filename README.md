Desafio AWS EC2 - DIO

Este repositório foi criado para documentar o desafio da DIO sobre gerenciamento de instâncias EC2 na AWS, e mostrar os conhecimentos adquiridos durante as aulas do módulo.

Objetivo do Desafio

Configurar e gerenciar uma instância EC2 na AWS, aplicando na prática os conceitos aprendidos durante o curso, e registrar toda a experiência de forma clara e organizada.

Aprendi a:

- Criar e configurar uma instância EC2 do tipo **t2.micro**;
- Entender os conceitos de regiões, zonas de disponibilidade e tipos de instância;
- Gerar e utilizar chaves SSH para conectar-se remotamente;
- Instalar pacotes e configurar um servidor web;
- Gerenciar segurança e permissões via Security Groups (regras de entrada e saída);
- Encerrar e remover instâncias de forma segura.
- Criar luxograma da Arquitetura draw.io
